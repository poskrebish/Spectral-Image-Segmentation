# Spectral Image Segmentation

Сегментация изображения через спектральное разбиение графа. Каждый пиксель — вершина графа, веса рёбер кодируют близость пикселей по яркости и расстоянию. Задача сегментации сводится к обобщённой задаче на собственные значения (normalized cut), а решение — к поиску младших собственных векторов.

Реализованы с нуля обратная итерация, обратная итерация с фиксированным сдвигом, итерация Релея с адаптивным сдвигом и блочная обратная итерация с методом Релея–Ритца. Финальная сегментация изображения выполняется через K-means в пространстве найденных собственных векторов.

## Реализованные методы

- Обратная итерация
- Обратная итерация с фиксированным сдвигом
- Итерация Релея с адаптивным сдвигом
- Блочная обратная итерация
- Метод Релея–Ритца
- K-means в спектральном пространстве
